and

1. Export your resume from Word, Canva, LaTeX, or Figma as a PDF.
2. Name it `Kaviyan_T_Resume.pdf` (or `resume.pdf`).
3. Replace the file in `d:/portfoli/public/` and `d:/portfoli/public/resume/`.
4. When visitors click **"Download Resume"**, this exact file downloads immediately.
5. When visitors click **"View Resume"**, this exact file opens in a new tab with the browser's PDF viewer.
